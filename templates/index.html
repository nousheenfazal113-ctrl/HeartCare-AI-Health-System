About HeartCare

Machine learning powered health assessment

HeartCare AI Health System is a machine learning based application designed to estimate heart disease risk using clinical patient information.

The system uses a trained Random Forest classifier to analyze 13 clinical features and provide a predicted risk level along with a probability score.
